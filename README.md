# Inside Taylor Bright

An animated, single-page portfolio built for GitHub Pages.

## Files

- \`index.html\` — semantic page structure and six miniature SVG rooms
- \`styles.css\` — visual system, responsive layout and all scene animation
- \`script.js\` — book opening, room details, nixie display and evidence mode
- \`photo.jpg\` — Taylor's portrait
- \`taylor-bright-cv.pdf\` — downloadable CV

There is no build step and no framework. GitHub Pages can serve the repository directly.

## Interaction

1. Select Taylor's portrait or **Open the workshop**.
2. The portrait opens from the centre and reveals two mirrored profile-shaped wings.
3. Select any of the six rooms to read the career evidence behind it.
4. Use **Evidence mode** for the conventional recruiter view.

The page supports keyboard navigation, responsive layouts, reduced-motion preferences, direct room URLs and a printable evidence view.

## Publishing

The production GitHub Pages site deploys from \`main\`. Merge the redesign pull request into \`main\`; GitHub Pages will then publish the new static files automatically.
